# Architecture Decision Records (ADRs)

Numbered, immutable records of architectural decisions (`NNNN-title.md`, MADR template).
A superseded decision gets a new ADR that references the old one — history is never rewritten.

The initial index (ADR-0001 … ADR-0012) is defined in
[implementation plan, Appendix D](../detailed_implementation_plan.md#appendix-d--initial-adr-index-created-in-phases-02);
the MADR template and first records land in Phase 0, step 3.
